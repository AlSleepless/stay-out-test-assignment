## Требования

* CMake версии 3.10 или младше
* Компилятор с поддержкой C++17 
* Библиотека GoogleTest (скачивается при сборке модульных тестов)

## Сборка

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## Запуск

```bash
./stayout_parcer <путь_к_файлу>
```

```bash
./tests/stalker_tests
```
